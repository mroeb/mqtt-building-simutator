Press Walk mode, then click the view. Move with W A S D, look with the mouse, press E to interact with doors, locks and lights. Esc releases the mouse — click the view to grab it again.

How to play

Walk into a room and its occupancy and motion sensors trigger immediately — the blueprint scripts react (for example the lights turn on).
E interacts with the nearest device: room door lock, ceiling lights and the garage door.
A locked door blocks the doorway. Every interaction is published as a normal MQTT actuator command, so watch the Dashboard event log and the energy meter while you play.
The 3D view loads Three.js from a CDN, so it needs an internet connection the first time.

Building Structure

Building → Floor → Room. New rooms start their own MQTT sensor, actuator, controller and energy tasks immediately.

Add Sensor or Actuator

Each device receives a unique ID and MQTT topic from the server. Sensor devices can be used as blueprint inputs. Actuators can be controlled by blueprint outputs.

Blueprint Help

1. Create or select a script.
2. Add nodes from the library.
3. Drag nodes by their header.
4. Click an output pin, then a matching input pin.
5. Save the script.

Blue pins: numeric values
Purple pins: boolean values

Example:
CO₂ Sensor → A > B → Ventilation
Connect a number constant of 1000 to input B.
